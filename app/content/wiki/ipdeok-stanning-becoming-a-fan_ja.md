## 1. はじめに

"입덕"（イプドク、発音は「イプドク」に近い）は、K-POPファン文化の中心となる韓国語のスラングで、特定のアイドルグループ、アーティスト、俳優、あるいは特定の興味の対象の熱心なファン、つまり「推し」になる行為や過程を表します。これは、「入口」（イプク）と「덕질」（ドクジル）という言葉を組み合わせた造語です。「入口」は文字通り「入り口」や「ゲートウェイ」を意味し、「덕질」は、特定の対象（アイドル、ドラマ、ゲームなど）に夢中になり、情熱を様々な形で表現するファン活動全般を指します。つまり、「입덕」は「オタ活の世界に入る」ことを意味します。それは、お気に入りの世界への扉を開き、活気に満ちた、魅力的で、しばしば没頭してしまう世界に足を踏み入れるようなものです。

イプドクという概念は、単にアーティストの音楽を楽しんだり、才能を称賛するだけではありません。それは、ファン活動への積極的な参加、アイドルへの感情的なつながりの育成、そして多くの場合、時間と資源の多大な投資を特徴とする、より深いレベルの関与への意識的な決定、または潜在意識的な引き寄せを表しています。

## 2. 語源と意味の内訳

"입덕"を完全に理解するためには、その構成要素を詳しく調べる必要があります。

*   入口 (Ip-gu / イプク): これは文字通り「入り口」「ゲートウェイ」「オープニング」を意味します。 イプドクの文脈では、誰かが熱心なファンになる道へと進む最初のきっかけや興味のポイントを表します。 この「入口」は、魅力的なミュージックビデオ、説得力のあるパフォーマンス、魅力的なバラエティ番組への出演、または単に友人からの紹介である可能性があります。

*   덕질 (Deok-jil / ドクジル): これは、熱心なファンであることに関連するすべての活動と行動を網羅する、より広範な用語です。 ドクジルは、特定の対象（アイドル、ドラマ、ゲームなど）に熱心に取り組み、さまざまな方法で自分の情熱を表現することを含みます。 ドクジルの例としては、次のものがあります。
    *   ストリーミング: ミュージックビデオや曲を積極的にストリーミングして、再生回数やチャートランキングを上げること。
    *   アルバムとグッズの購入: アーティストをサポートし、記念品を収集するために、CDアルバム、ペンライト、フォトカード、衣類、その他の関連グッズを購入すること。
    *   コンサートとファンミーティングへの参加: ライブパフォーマンスやファンイベントに出かけ参加すること。
    *   ファンコンテンツの作成: ファンフィクションを書いたり、ファンアートを描いたり、ファン編集を作成したり、コンテンツを翻訳したり、アーティストに触発された他の形式の創造的な表現を作成したりすること。
    *   オンラインコミュニティへの参加: ソーシャルメディアプラットフォーム、ファンフォーラム、アーティストに特化したオンラインコミュニティで議論に参加すること。
    *   音楽番組やアワードでの投票: アーティストをサポートし、賞を獲得するために、オンラインやテキストメッセージの投票に積極的に参加すること。
    *   ファンプロジェクトの企画と参加: 他のファンと協力して、イベント、チャリティー活動、またはアーティストへのサポートを示すその他のイニシアチブを企画すること。
    *   韓国語の学習: 多くの海外ファンは、アーティストのインタビュー、歌、ソーシャルメディアの投稿をよりよく理解するために、時間をかけて韓国語を学習します。

したがって、「입덕」は基本的に「덕질」の旅に乗り出す行為、つまり熱心で積極的に関与するファンになる出発点です。

## 3. 「Ipdeok」の段階

すべての人の経験はユニークですが、「입덕」のプロセスは、多くの場合、関与と投資のレベルが上がるにつれて、一般的なパターンに従います。

*   最初の露出と興味 (入口): これは興味を刺激する最初の火花です。 キャッチーな曲を聞いたり、目を引くミュージックビデオを見たり、バラエティ番組でアイドルのパフォーマンスに気づいたりする可能性があります。

*   カジュアルなリスニング/視聴: 個人はアーティストの音楽を聴いたり、コンテンツをより定期的に視聴したりし始めます。 アーティストとそのグループについてもっと知るために、オンラインで気軽に閲覧するかもしれません。 これは探求と情報収集の段階です。

*   メンバー/個性の発見: 個人はメンバーの名前、グループ内での個々の役割、そして個性を学び始めます。 各メンバーをよりよく理解するために、バラエティ番組や舞台裏のコンテンツを見始めるかもしれません。

*   推しを選ぶ (최애/Choeae / チェエ): これはイプドクのプロセスにおける重要なマイルストーンです。 「Choeae」とは、グループ内のお気に入りのメンバーを指します。 この選択は、多くの場合、視覚的な魅力、才能、個性、またはその3つの組み合わせを含むさまざまな要因に基づいています。 推しがいることは、グループへの感情的なつながりを強化し、さらなる関与を促進します。 グループのメンバー数に応じて「OT#」であることも完全に許容できることに注意することが重要です。これは「One True [Number]」を意味し、グループのすべてのメンバーを平等に愛していることを示します。

*   積極的なファン活動への参加: これは、個人が「덕질」のライフスタイルを完全に受け入れるポイントです。 ストリーミング、投票、アルバムの購入、オンラインコミュニティへの参加など、ファン活動に積極的に参加し始めます。 彼らはグループの成功により投資し、ファンダムの努力に積極的に貢献します。

*   深い感情的な投資: 個人はアーティストとグループへの強い感情的な愛着を育みます。 彼らはグループの業績に誇りを感じ、困難な時期には心からの悲しみを経験するかもしれません。 この感情的な投資は、熱心な「推し」であることの重要な特徴です。

*   「決してファンをやめない」(탈덕 불가/Taldeok Bulga / 脱덕 불가): これは、個人が長期的にはファンダムに「詰まっている」可能性が高いことを認識している、よりユーモラスで自覚的な段階です。 彼らは非常に多くの時間、エネルギー、感情を投資しており、去ることは不可能だと感じています。 「Taldeok Bulga」は文字通り「ファンダムからの脱出は不可能」を意味します。

## 4. K-POP文化における「Ipdeok」の意義

「Ipdeok」は単なるシンプルな用語ではありません。それは、K-POP文化の重要な側面、つまりファンの積極的かつ熱心な参加を反映しています。 K-POPの成功は、主に信じられないほど献身的なファン層に起因しており、彼らはストリーミング、投票、その他の形のサポートを通じてお気に入りのアーティストを積極的に宣伝しています。 したがって、「Ipdeok」は、ファンがエコシステムにおいて果たす積極的な役割と、アーティストの人気への貢献を認識しています。

この概念はまた、K-POPファン層の共同体的側面を強調しています。 「推し」になることは、多くの場合、共通の情熱を共有する志を同じくする個人のコミュニティに参加することを含みます。 この帰属意識と共有された経験は、多くのファンにとって強力な魅力であり、グループへのコミットメントをさらに強化します。 イプドクの共有された経験は、地理的な境界、年齢層、文化的な背景を超えてファンを結びつけます。

## 5. K-POPを超えて: 他の文脈での「Ipdeok」

「Ipdeok」はK-POPファンダムの文脈で生まれましたが、その用語は他の関心領域を包含するように拡大しました。 それは、ドラマ、アニメ、ビデオゲーム、スポーツチーム、または情熱的な献身を促すその他の趣味や興味に深く投資することの表現にも使用できます。 コアとなる概念は同じままです。それは、誰かがカジュアルな興味から熱心なファン層への敷居を越える瞬間を意味します。

## 6. 関連用語

「Ipdeok」を理解するには、多くの場合、K-POPファン層の用語集に含まれる関連用語に精通している必要があります。

*   덕질 (Deokjil / ドクジル): 前述のように、これは情熱的なファン活動を指します。
*   최애 (Choeae / チェエ): グループ内のお気に入りのメンバー (推し)。
*   차애 (Chae / チャエ): グループ内で2番目に好きなメンバー (2番目の推し)。
*   올팬 (Olpaen / オルペン): グループのすべてのメンバーを平等にサポートするファン (OT#)。
*   탈덕 (Taldeok / 脱덕): ファンダムを去る行為。 「Ipdeok」の反対。
*   입덕 부정기 (Ipdeok Bujeonggi / イプドク ブジョンギ): 「否定」段階。誰かがIpdeokの兆候を示していても、ファンになっていることを認めるのを拒否するかもしれません。
*   머글 (Meogeul / モグル): ハリーポッターシリーズから借用した用語で、特定のファン層の一部ではない人 (ファンではない人) を指します。
*   성덕 (Seongdeok / ソンドク): 「성공한 덕후」 (Seonggonghan Deokhu / 成功したオタク) の略で、「成功したファン」を意味します。 この用語は、アイドルに会ったり、アイドルから認識されたり、関連分野で働いたりするなど、ファン層に関連する重要な目標を達成したファンを説明するために使用されます。
*   입덕요정 (Ipdeok Yojeong / イプドク ヨジョン): 「Ipdeok妖精」。カリスマ性と魅力にあふれ、特に新しい人々をファン層に引き込むのに長けていると見なされる人物。

## 7. 結論

「입덕」（Ipdeok）は、熱心なK-POPファンになる旅をカプセル化した豊かで多面的な用語です。 これは、K-POP文化の力とそのグローバルファン層の揺るぎない献身の証です。 「Ipdeok」を理解することは、K-POPファンダムのダイナミクスと、その継続的な成功を推進する情熱的な関与への貴重な洞察を提供します。 これは、「덕질」の道を歩むことを選択した人々にとって、充実した、しばしば人生を変える経験の始まりを表しています。
